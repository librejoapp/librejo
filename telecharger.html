Télécharger

Librejo s’installe depuis le navigateur. Voici ce qui se télécharge en plus.

  • Le dossier de test

    Une structure fictive, l’Association des Tilleuls, pour essayer sans risque. Mot de passe admin : test.

    Télécharger le dossier de testOu essayez-le directement en ligne
    Fichier zip, à décompresser avant de le choisir dans Librejo. En ligne, rien à installer : la démo s’ouvre sur cette structure fictive, et tout reste dans votre navigateur.

  • Le code source

    Tout le code de Librejo est public. Chacun peut le lire, le vérifier et proposer des améliorations.

    Voir le code sur GitHub

  • La version hors ligne

    Pour les structures sans Internet : un dossier à copier, sans installation.

    Bientôt disponible.

    Trois documents en PDF, à imprimer ou à envoyer à vos collègues.
