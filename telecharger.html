Télécharger

Librejo, sa version hors ligne, le dossier de test, le code et les guides.

  • Librejo

    La version complète, pour votre structure. Elle s’installe depuis Chrome ou Edge, sans fichier à télécharger : une icône Librejo apparaît sur le bureau, comme pour un logiciel.

    Installer LibrejoGratuit, sans compte et sans abonnement.

  • La version hors ligne

    Pour les structures sans Internet, ou dont l’informatique bloque l’installation : un dossier à décompresser là où l’équipe range ses documents, puis Librejo.html à ouvrir avec Chrome ou Edge. Les mises à jour se font à la main, en remplaçant les fichiers.

    Télécharger la version hors ligneFichier zip de 5 Mo. Le mode d’emploi est dans le fichier LISEZ-MOI.

  • Le dossier de test

    Une structure fictive, l’Association des Tilleuls, avec vingt et un documents inventés. Mot de passe admin : test.

    Télécharger le dossier de testFichier zip, à décompresser avant de le choisir dans Librejo.

    Tout le code de Librejo est public. Chacun peut le lire, le vérifier et proposer des améliorations.

    Voir le code sur GitHub
