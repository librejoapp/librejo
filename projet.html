Le projet

Un outil né sur le terrain, proposé aux autres équipes.

  • D’où vient Librejo

    Librejo est né dans un CSAPA-CAARUD de Marseille, pour ranger les documents d’une équipe. Il est maintenant proposé aux structures sociales et médico-sociales, de la petite association au service.

  • Nous écrire

    Une question, une erreur, l’envie d’essayer avec votre équipe ? Nous répondons à chaque message.

    librejo@proton.me

  • Où en est le projet

    Librejo est en développement actif. Testez-le avec le dossier de test avant d’y ranger vos vrais documents, et faites valider son usage par votre direction.

    Le dossier de test

  • Un code ouvert

    Tout le code est public : chacun peut le lire et le vérifier. Librejo est gratuit, sans abonnement.

    Voir le code sur GitHub
